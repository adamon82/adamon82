# משרות פעילות · אפליקציה לאייפון

אפליקציית SwiftUI עם ווידג'ט למסך הבית. הנתונים נשמרים בטבלת **משרות פעילות** ב-Notion,
אותה טבלה שהלוח ב-Claude והסשנים שלך מעדכנים.

## הרצה ראשונה (בערך 10 דקות)

1. במק, בטרמינל:
   ```bash
   brew install xcodegen
   cd ios/ActiveJobs
   xcodegen
   open ActiveJobs.xcodeproj
   ```
2. ב-Xcode: בוחרים את הפרויקט › Signing & Capabilities. בשני ה-targets (ActiveJobs ו-ActiveJobsWidget)
   בוחרים Team (חשבון ה-Apple שלך).
   - אם Xcode מתלונן על ה-Bundle ID, משנים את `app.activejobs` לשם ייחודי משלך, בשני ה-targets.
   - **App Groups** (בשביל הווידג'ט) דורש חשבון מפתח בתשלום. בחשבון חינמי מוחקים את ה-capability
     מ-Signing & Capabilities. האפליקציה תעבוד, אבל הווידג'ט לא יקבל את המפתח.
3. מחברים את האייפון בכבל, בוחרים אותו למעלה ולוחצים ▶︎.
   באייפון: הגדרות › כללי › VPN וניהול התקנים › מאשרים את המפתח. בפעם הראשונה צריך גם להפעיל
   הגדרות › פרטיות ואבטחה › Developer Mode.

## חיבור ל-Notion (פעם אחת)

1. ב-https://www.notion.so/profile/integrations יוצרים **Internal integration** בשם "משרות".
2. מעתיקים את ה-**Internal Integration Secret**.
3. בטבלת **משרות פעילות** ב-Notion: ⋯ › **Connections** › מוסיפים את "משרות".
4. באפליקציה: ⚙︎ › מדביקים את המפתח › **שמירה ובדיקה**.

## מה יש באפליקציה

- רשימה לפי חברה או לפי סטטוס, חיפוש, וסינון לפי סטטוס.
- **החלקה ימינה:** "פעילה" או "+ פנייה". **החלקה שמאלה:** "בהמתנה" או "נסגרה".
- לחיצה על משרה פותחת אותה. כל שינוי נשמר לבד ב-Notion.
- "דורש טיפול": משרות לאימות ומשרות פעילות שלא עודכנו 14 יום.
- ווידג'ט קטן ובינוני. מוסיפים אותו בלחיצה ארוכה על מסך הבית › ＋ › "משרות".
- משיכה למטה מרעננת. האפליקציה גם מרעננת לבד כל פעם שחוזרים אליה.

## חשבון חינמי או בתשלום

- **בחינם:** האפליקציה עובדת 7 ימים, ואז מריצים שוב מ-Xcode. אין ווידג'ט.
- **בתשלום ($99 לשנה):** אפשר להתקין דרך TestFlight, האפליקציה לא פגה, והווידג'ט עובד.
